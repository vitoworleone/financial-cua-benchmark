# 金融 CUA Benchmark

> 一套用于设计和验证金融 Computer-Use Agent（CUA）任务的评测框架。

金融 Agent 的价值不只在于“能生成一份内容”，而在于能否在明确的业务约束下完成工作：使用正确的主体、期间、口径与单位，满足业务勾稽关系，保留来源依据，并形成可复核的最终结果。

本项目围绕这一问题，构建金融任务设计方法、确定性 Verifier、任务目录和债券承做工作流案例。

## 核心方法

每个任务都定义为一次可验证的状态转移：

```text
(t, c, s_init, s_gold, r)
```

| 元素 | 含义 |
| --- | --- |
| `t` | Agent 可见的任务指令 |
| `c` | 主体、期间、文件、政策、输出合同与限制组成的上下文 |
| `s_init` | 可复现的初始状态 |
| `s_gold` | 正确的目标业务状态 |
| `r` | 对最终可观察状态进行判定的 Verifier |

这使评测从“答案像不像”转向“任务是否真正完成”。

## Verifier 设计

Verifier 不依赖“文件存在”或“页面显示成功”来判分，而是组合以下检查：

- **元数据检查**：主体、期间、口径、单位与任务合同一致；
- **字段真值检查**：关键字段和普通字段分别校验；
- **业务勾稽检查**：报表平衡、现金滚动、实际利率法摊还等公式；
- **来源映射检查**：每个关键结果可追溯到输入来源；
- **提交状态检查**：验证最终状态，而不是只相信文字说明；
- **安全门禁**：识别输入篡改、越权读取与不合规写入。

详见 [Verifier 架构](docs/03-verifier-architecture.md) 和 [校验项说明](docs/04-checker-guide.md)。

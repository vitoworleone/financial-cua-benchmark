# Verifier 架构

## 输入与输出

```text
Agent 提交物 + 最终环境状态 + 初始快照
        + 业务政策 + 正确结果 + 版本信息
                              ↓
                         预检与归一化
                              ↓
                         任务级检查器
                              ↓
                         评分与失败门禁
                              ↓
                    结构化结果与诊断明细
```

Verifier 的输出包含总分、是否通过、已触发的封顶规则，以及各检查器的诊断信息。

## 检查器体系

| 类别 | 关注的问题 | 示例 |
| --- | --- | --- |
| 元数据 | 做的是不是正确任务 | 主体、期间、口径、单位 |
| 字段真值 | 填的值是否正确 | 关键合计、税额、现金余额 |
| 内部勾稽 | 提交内容是否自洽 | 资产负债平衡、现金滚动、期间摊还 |
| 来源映射 | 结果能否追溯 | 字段到文件、页码、表格单元格或计算规则 |
| 交付状态 | 是否真正完成 | 必交文件、后端提交状态 |
| 安全门禁 | 是否遵守任务边界 | 输入完整性、隐藏信息访问、越权写入 |

## 评分机制

每个检查器给出 `PASS`、`FAIL` 或 `BLOCKED`，并附带权重和诊断说明：

```text
基础分 = 所有 PASS 检查器权重之和
最终分 = 基础分经过业务红线和封顶规则处理后的结果
```

例如：关键字段错误可限制最高分，报表不平衡或本金滚动失败可直接阻断通过，输入被篡改则记为安全失败。

## 三类实现示例

### 资产负债表

同时检查字段真值、资产负债权益平衡、资产小计、负债小计、来源和提交状态，避免“通过两个错误数字配平”的假通过。

### 现金流量表

检查经营、投资、筹资活动与现金净变动的关系，并验证期初现金、净变动和期末现金的滚动关系。

### 融资租赁 ACT/360 摊还表

根据年利率、实际天数和付款日逐期重算利息、本金和期末余额；再检查期次连续性、残值收敛、汇总与来源映射。

## 任务级扩展

共享核心负责归一化、评分、输入完整性和提交状态。每个任务只定义自身的字段、公式、关键检查器与业务红线，因此可以扩展到税务、银行、基金、保险、证券和债券承做场景。
